# 📊 Gestão

Sistema de gestão desenvolvido em **TypeScript** e **Python**, voltado para a manipulação de dados, execução de rotinas de importação de arquivos JSON e comunicação via APIs HTTP.

---

## 🛠️ Tecnologias Utilizadas

* **[TypeScript](https://www.typescriptlang.org/)**: Linguagem principal para estruturação do código e regras do sistema.
* **[Node.js](https://nodejs.org/)**: Ambiente de execução JavaScript do lado do servidor.
* **[Python](https://www.python.org/)**: Linguagem utilizada em scripts auxiliares para processamento e manipulação de arquivos JSON.
* **REST / HTTP**: Testes e consumo de rotas/APIs HTTP.

---

## 📁 Estrutura de Pastas e Arquivos

```text
gest-o/
├── .vs/                # Configurações do ambiente de desenvolvimento (Visual Studio)
├── src/                # Código-fonte principal em TypeScript
├── importjson.py       # Script Python para importação e tratamento de dados em JSON
├── request.http        # Arquivo contendo requisições HTTP configuradas para testes
├── package.json        # Gerenciador de dependências e scripts do Node.js
├── package-lock.json   # Mapeamento exato das versões das dependências do Node.js
├── tsconfig.json       # Configurações do compilador TypeScript (tsc)
├── .gitignore          # Arquivos e pastas ignorados pelo Git
└── README.md           # Documentação principal do projeto
